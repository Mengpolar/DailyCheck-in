# 每日打卡 DailyCheck-in

深空主题的安卓打卡应用：把循环周期性任务变成**轨道上的一颗颗行星**——
主界面是一片星空轨道盘，每次打卡点亮一颗行星并拖出彗尾；
操作界面则是一台**服役多年的宇航设备**，银色金属外壳里嵌着天蓝荧光的 CRT 屏幕。

## 功能

- 🪐 **星空轨道盘**：每个任务一条独立轨道，行星沿椭圆轨道实时公转
  - 扫描（原打卡）后行星点亮并拖出彗尾，彗尾上星光粒子向末端漂移渐隐
  - 逾期/临近到期以红圈/琥珀脉冲提示；过期一次性任务化作**暗星**停靠盘外空白区
  - 空白区上下滑动调整轨道盘倾角（惯性滑行 + 三档吸附）
- 🌱 **行星成长系统**：以累计扫描次数分级——星胚(0)→微星(7)→岩星(15)→虹星(30)→环星(50)→炽星(75)→耀星(100)，
  每阶段为行星多叠一层特效（大气缘光/地貌纬度带/极光环/行星环/自体辉光/日冕耀斑）
- 🎯 **聚焦模式**：点击行星或暗星推近镜头，目标居中放大
  - 长按扫描：琥珀→天蓝填充 3 秒，行星自下而上恢复色彩
  - 回溯扫描：上一周期漏扫时出现在扫描键上方，补录记录标记为「补」（不记具体时刻）
  - 长按吞噬：票根式分隔的红色删除区，行星螺旋坠入盘心塌缩为虚空（暗星原地塌缩）
  - 长按重构：聚焦暗星时扫描键变为重构，恢复为正常有轨行星（窗口从今天重新起算）
  - 陀螺仪质感：翻转/俯仰手机时行星明暗面移动、高光扫动、轮廓压缩
  - `<<<` / `>>>` 在行星与暗星间平滑切换镜头
- 🧭 **筛选与补位**：月球导航上的筛选键循环「全部/未完成/已完成」，
  行星渐隐消散、轨道补位让位，全程平滑插值
- 📋 **行星名录**：月球导航「列表」键打开，按轨道环序卡片展示（序号/状态/扫描次数/成长阶段），
  按住左侧手柄拖动排序（主屏轨道随之重排），点击卡片直达聚焦
- 🌌 **星海**：已完成的一次性任务过期后安息于星海——固定坐标、不随轨道转动，
  可聚焦；名录「星海」入口进入，改造可将其召回轨道
- 🖥 **宇航设备面板**：新建/改造/设置/追溯均为「设备模块」风格——
  金属外壳（拉丝/铆钉/划痕）+ CRT 屏幕（网格/扫描光波/半透明透视星空），
  全中文终端字段，金属反光随陀螺仪漂移
- ⬇️ **应用内更新**：启动静默检查 GitHub Releases，多镜像容错下载 APK 并校验
- 🔒 数据全部保存在本地（单 JSON 文件 + 行星图片目录），不上传任何服务器

设计语言约定：**外壳负责"旧"，屏幕负责"活"** ——金属是哑光磨损的，屏幕是天蓝荧光
响应式的。界面色集中定义在 `DeviceUi.kt`（天蓝主色 `#6BE3FF` / 灰黑屏底 / 荧光警示红）。

## 构建与发布

```bash
./gradlew assembleRelease          # 本地构建：签名凭据读 keystore/signing.properties（git 忽略）
```

**签名**：release 密钥库不入库——本地凭据在 `keystore/signing.properties`（storeFile/storePassword/keyAlias/keyPassword），
CI 凭据在仓库 Secrets（`RELEASE_KEYSTORE_BASE64` / `RELEASE_KEYSTORE_PASSWORD` / `RELEASE_KEY_ALIAS` / `RELEASE_KEY_PASSWORD`），
两者皆缺时回退 debug 签名（公开克隆仍可构建但不可发布）。应用内更新会校验下载包与已装应用签名一致，异签名包拒装。

版本号由 git tag 自动注入（CI 读取 tag → `versionName`/`versionCode`）：

```bash
git commit -m "feat: xxx"
git tag v0.1.1 && git push origin main v0.1.1   # 推送 tag 触发 GitHub Actions 构建发布
```

## 应用内更新机制

1. 启动时（可开关）或手动触发，调用 GitHub API `releases/latest` 比较版本号
2. 发现新版本后经多镜像（gh-proxy 系 → GitHub 直连）容错下载 APK，校验 PK 头
3. 下载完成调起系统安装器；首次安装需允许「安装未知应用」
